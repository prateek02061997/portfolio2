AI CV Assistant

AI-powered resume optimization assistant for ATS improvement, resume enhancement, and tailored cover letters.

Overview

An assistant that analyzes CV quality and returns practical improvements for recruiter impact and ATS compatibility.

Problem Statement

Job seekers often submit resumes that are not optimized for ATS filters or role-specific expectations.

Solution

AI analyzes input resumes, identifies weak sections, and generates revised content and tailored cover letters.

Technologies

Gemini API, Claude API, Python, Telegram Bot, Prompt Engineering, Document Generation.

Architecture

User Input -> Prompt Router -> LLM Layer -> Resume Evaluation Engine -> Recommendation Builder -> Output.

Features

Resume analysis, ATS recommendations, cover letter generation, role-specific optimization prompts.

Challenges

Balancing role-specific recommendations with consistent formatting and reducing generic AI output.

Future Improvements

Resume benchmark scoring, multilingual support, and job-description specific keyword tuning.
